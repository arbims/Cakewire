Limites connues

  • Morph sans plugin Alpine dédié — parfois wire:ignore pour JS tiers.
  • Pas de file d’attente offline — échec réseau = pas de retry automatique.
  • Alpine requis — sans JS, HTML initial uniquement.
  • Une action par requête — pas de batching avancé Livewire v3.
