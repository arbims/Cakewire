Documentation CakeWire

CakeWire reproduit le modèle Livewire 3 pour CakePHP 5 : composants PHP, état synchronisé avec le navigateur, actions serveur, directives wire:* dans le HTML, et runtime Alpine.js 3.

Principe

Le navigateur n’exécute jamais la logique métier. Il envoie l’état JSON du composant et éventuellement le nom d’une action ; PHP met à jour l’état, re-rend le HTML interne, et renvoie { "html", "state" }. Le client met à jour le DOM via morphdom (voir Morph DOM).
