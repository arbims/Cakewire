Installation

Packagist : cakewire/cakewire — Code : github.com/arbims/Cakewire

Composer (release stable)

Nécessite un tag semver sur GitHub (ex. v1.0.0) indexé par Packagist.

composer require cakewire/cakewire

Composer (branche main)

Si Packagist ne propose que dev-main et que votre projet exige stable :

composer require cakewire/cakewire:dev-main@dev

Dépôt VCS direct

{
    "repositories": [
        {
            "type": "vcs",
            "url": "https://github.com/arbims/Cakewire"
        }
    ],
    "require": {
        "cakewire/cakewire": "^1.0"
    }
}

Plugin CakePHP

Fichier config/plugins.php (souvent auto via cakephp/plugin-installer) :

<?php
return [
    'CakeWire\CakeWirePlugin' => [],
];

Helper CakePHP

Dans src/View/AppView.php :

public function initialize(): void
{
    parent::initialize();
    $this->addHelper('CakeWire.CakeWire');
}

Layout — assets runtime

Recommandé (séparer head et body) :

<!-- dans <head> -->
<?= $this->CakeWire->headAssets() ?>

<!-- avant </body> -->
<?= $this->CakeWire->runtimeScripts() ?>

Équivalent en une ligne : <?= $this->CakeWire->scripts() ?>

MéthodeContenu
headAssets()Meta CSRF (csrfToken), CSS wire:loading / wire:cloak
runtimeScripts()morphdom.min.js, cake-wire.js, Alpine.js 3 (CDN, defer)
scripts()headAssets() + runtimeScripts()
Ordre obligatoire : morphdom.min.js puis cake-wire.js sans defer, avant Alpine (defer). Alpine enregistre cakewireShell dans alpine:init — le runtime CakeWire doit déjà être chargé.

Les scripts incluent un paramètre de version (?v=…). Après mise à jour du plugin, incrémentez CakeWireHelper::RUNTIME_VERSION si les utilisateurs voient un ancien JS en cache.

Enregistrer un composant

config/bootstrap.php :

use Cake\Core\Configure;

Configure::write('CakeWire.components.counter', \App\CakeWire\CounterComponent::class);
Configure::write('CakeWire.components.contact-form', \App\CakeWire\ContactFormComponent::class);

Alias autorisés : [a-z][a-z0-9-]* uniquement.

Monter un composant dans une vue

<?= $this->CakeWire->component('counter', ['count' => 0]) ?>

HTML produit (simplifié) :

<div
  data-cakewire-config="{&quot;component&quot;:&quot;counter&quot;,...}"
  data-cakewire-alias="counter"
  x-data="cakewireShell()">
  <!-- HTML interne du composant -->
</div>
  • data-cakewire-config — JSON (alias, endpoint, état initial)
  • data-cakewire-alias — ciblage $dispatch->to('…')
  • x-data="cakewireShell()" — racine Alpine (ne pas mettre CakeWire.shell() dans le HTML)

Configuration optionnelle

Configure::write('CakeWire.templates', ROOT . 'templates' . DS . 'CakeWire' . DS);
