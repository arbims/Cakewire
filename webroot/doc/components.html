Composants & vues

Génération CLI

bin/cake cakewire component TodoList
bin/cake cakewire component TodoList --register
bin/cake cakewire component Reports --view=reports/index --force

Crée src/CakeWire/TodoListComponent.php et templates/CakeWire/todo-list.php.

Classe de base

Étendez CakeWire\Component\Component. Déclarez :

  • propriétés publiques pour l’état synchronisé ;
  • protected array $actions = ['save', …]; — whitelist des méthodes appelables ;
  • optionnel : $validationRules, $uploads.

render() et view()

use CakeWire\Component\Component;
use CakeWire\View\ComponentTemplate;

use function CakeWire\view;

final class ShowPosts extends Component
{
    public function render(): ComponentTemplate
    {
        return view('posts/list');
    }
}

Fichier : templates/CakeWire/posts/list.php

Résolution des noms

Argument view()Fichier
'counter'templates/CakeWire/counter.php
'posts/list'templates/CakeWire/posts/list.php
'livewire.show-posts'templates/CakeWire/show-posts.php
'cakewire.posts.list'templates/CakeWire/posts/list.php

Préfixes livewire. / cakewire. ignorés ; . → /. Pattern : [a-z][a-z0-9\-\/]*.

Le helper CakeWire\view() est chargé via Composer (src/functions.php). Exécutez composer dump-autoload après installation du plugin.

Exemple complet

Composant :

final class CounterComponent extends Component
{
    public int $count = 0;
    protected array $actions = ['increment', 'decrement', 'reset'];

    public function increment(): void { $this->count++; }

    public function render(): ComponentTemplate
    {
        return view('counter');
    }
}

Vue templates/CakeWire/counter.php :

<div>
    <h1>Compteur : {{ $count }}</h1>
    <button type="button" wire:click="increment">+1</button>
</div>

Rétrocompatibilité

  • Sans surcharge de render() : inférence CounterComponent → counter, ou protected string $view = '…';
  • render(): string — HTML brut (tests, markup minimal)

Validation

protected array $validationRules = [
    'email' => 'required|email|maxLength:255',
    'name' => 'required|minLength:2',
];

public function submit(): void
{
    if (!$this->validate()) {
        return;
    }
    // ...
}

Règles : required, email, maxLength:N, minLength:N.

Méthodes utiles : addError, resetErrors, hasError, error('field') dans le template via @error.
