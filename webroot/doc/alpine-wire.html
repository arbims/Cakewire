Objet magique $wire

Comme Livewire, CakeWire expose $wire dans les expressions Alpine à l’intérieur d’un composant monté (ancêtre [data-cakewire-config]). 

<input type="text" wire:model.live="title">
<p x-text="$wire.title.length + ' caractères'"></p>
<button type="button" x-on:click="$wire.title = ''">Effacer (local)</button>
<button type="button" x-on:click="$wire.set('title', '')">Effacer (sync serveur)</button>
APIDescription
$wire.propLecture / écriture locale de state.prop
$wire.get('prop')Lecture
$wire.set('prop', value)Écriture + sync('prop')
$wire.runAction('action', …)Action serveur
$wire.refresh()Re-rendu serveur ($refresh)
Enregistrement Alpine : Alpine.magic('wire', …) dans cake-wire.js.
