Débogage

Checklist

  • Console navigateur — erreurs de directive ou HTTP 4xx.
  • Onglet Network — requête POST /cake-wire/update, corps JSON, réponse { html, state }.
  • Meta csrfToken présente dans le <head>.
  • Ordre scripts : morphdom → cake-wire → Alpine.
  • Paramètre ?v= sur cake-wire.js après mise à jour du plugin (hard refresh).

Codes HTTP

Code
403Token CSRF manquant ou invalide
400Action absente de $actions, alias inconnu, payload invalide

Erreurs JavaScript

MessagePiste
cakewireShell is not defined / wireIsLoading is not defined Alpine démarré avant cake-wire.js, ou cache JS obsolète
CakeWire is not mounted yet Clic avant fin du init() ; erreur JS antérieure
Invalid CakeWire action expression Syntaxe d’action incorrecte dans une directive

Tests PHPUnit

Simulez l’endpoint avec en-têtes CSRF et JSON :

$this->configRequest([
    'headers' => [
        'Accept' => 'application/json',
        'Content-Type' => 'application/json',
        'X-CSRF-Token' => $token,
    ],
    'cookies' => ['csrfToken' => $token],
]);
$this->post('/cake-wire/update', json_encode([
    'component' => 'counter',
    'state' => ['count' => 0],
    'action' => 'increment',
    'params' => [],
]));

wire:navigate

Vérifiez la zone [data-cakewire-navigate] dans le layout. Après navigation SPA, Alpine réinitialise les composants du fragment injecté.
