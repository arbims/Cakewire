Runtime & montage

Deux couches : PHP compile, JS complète

ÉtapeOùRôle
Premier HTML WireDirectiveCompiler (PHP) Transforme wire:click, wire:model, wire:loading, wire:error, etc. en attributs Alpine avant envoi au navigateur.
Après AJAX cake-wire.js (bindWire) Compile les directives restantes (wire:poll, wire:init, wire:dirty, …), puis Alpine.initTree().

Exemples de compilation serveur

Dans la vue PHPAlpine généré (extrait)
wire:click="increment"x-on:click.prevent="handleWireClick($event, 'increment')"
wire:model.live="email"x-model="state.email" + debounce sync
wire:loading wire:target="increment"x-show="wireIsLoading('increment')"
wire:error="email"x-show + x-text pour le message
wire:key="user-1"data-cakewire-key="user-1" (morph DOM)

Les handlers handleWireClick, handleWireSync, wireIsLoading, … sont définis dans cakewireShell() et délèguent à runAction, sync, etc. une fois le blueprint runtime fusionné.

Montage d’un composant (navigateur)

  1. Alpine instancie cakewireShell() (état vide + délégués).
  2. Le hook init() du shell lit data-cakewire-config, construit le blueprint (createComponent) et fusionne état, runAction, sync, polls, etc.
  3. Le init() du blueprint exécute bindWire pour les directives non compilées côté serveur.
