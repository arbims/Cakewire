Directives wire:*

Les directives courantes sont compilées en PHP (WireDirectiveCompiler). cake-wire.js complète au montage et après chaque réponse AJAX (poll, init, dirty, …).

Liaison — wire:model

Comme Livewire 3 : wire:model est différé (sync au change).

DirectiveComportement
wire:model="prop"Sync au change
wire:model.live="prop"Sync à la saisie (debounce 150 ms) + validation live
wire:model.live.debounce.300ms="prop"Debounce personnalisé
wire:model.live.throttle.150ms="prop"Throttle
wire:model.blur="prop"Sync au blur
wire:model.number="prop"Cast numérique
wire:model.boolean="prop"Booléen (checkbox)
 
<input type="text" wire:model.live.debounce.200ms="title">
<textarea wire:model="content"></textarea>
<input type="checkbox" wire:model.boolean="published">

Actions & événements

Toute directive wire:<événement> non réservée devient un listener Alpine.

DirectiveUsage
wire:click="save"Clic
wire:submit="save"Formulaire (prevent par défaut)
wire:keydown.enter="search"Touche Entrée
wire:keyup, wire:mouseenter, …Autres événements DOM
 
<button wire:click="increment">+</button>
<button wire:click="add(2, 'note')">Add</button>
<button wire:click="$refresh">Rafraîchir</button>

Paramètres : entiers, floats, booléens, null, chaînes '…' / "…".

wire:confirm

<button wire:click="delete" wire:confirm="Supprimer ?">Supprimer</button>

wire:loading et wire:target

DirectiveEffet
wire:loadingVisible pendant une requête
wire:loading.removeVisible sauf pendant le chargement
wire:loading.attrdisabled pendant le chargement
wire:loading.class="opacity-50"Classe conditionnelle
wire:loading.delay.200msAffichage après délai
wire:target="save"Filtre sur une action ou une propriété sync

wire:dirty

Compare state à serverState (dernière réponse serveur).

  • wire:dirty — état global modifié
  • wire:dirty="title" — une propriété
  • wire:dirty.remove, wire:dirty.class

wire:init

<div wire:init="loadData">...</div>

Appelle l’action (ou $refresh) une seule fois au premier montage Alpine.

wire:poll

<div wire:poll.5s="refresh">...</div>
<div wire:poll.30s="$refresh"></div>

Suffixes : .5s, .2m, .1h, .1d (défaut 2s).

DOM — ignore, cloak, key

DirectiveEffet
wire:ignorex-ignore — sous-arbre non géré par Alpine/morph
wire:cloakMasqué jusqu’à init
wire:key="id"Clé morphdom (data-cakewire-key)

$dispatch et wire:on

<button wire:click="$dispatch('item-added', { id: 1 })">Publier</button>
<button wire:click="$dispatch('item-added', { id: 1 })->to('event-listener')">Cibler</button>

<section wire:on:item-added="onItemAdded">...</section>

L’action réceptrice doit être dans $actions. Alias via data-cakewire-alias.

Erreurs — wire:error / @error

<input wire:model.live="email">
<span wire:error="email"></span>

Équivalent helper : <?= $this->CakeWire->error('email') ?>

Upload fichier

<input type="file" wire:model="avatar" accept="image/*">

Requête multipart/form-data ; stockage tmp/cakewire_uploads/.

wire:navigate

<a href="/contact" wire:navigate>Contact</a>
<main data-cakewire-navigate>...</main>

Délégation document sur a[href][wire:navigate]. Voir Morph DOM pour la mise à jour de la zone.
